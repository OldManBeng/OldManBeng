# 实施计划：佛法偈语注入 —— 晨钟·月轮·因果

## 设计总纲

**核心装置：「晨钟月轮」**——每天早上，引擎在动态流里敲响一条偈语（verse + 出处 + 贴合当下剧情的释义）。三十天 = 一轮完整的因果之轮，主题分组递进：

- **第 1-7 天「因缘」**——五个哥哥是怎么被各自的孤独找到的
- **第 8-14 天「贪·欲」**——红包开始流动
- **第 15-21 天「痴·面具」**——人设越换越多，茧越吐越厚
- **第 22-28 天「业·渐盈」**——水滴渐盈大器，评论区记账
- **第 29-30 天「归·悟」**——无常与放下

**首尾呼应的框架**：第 2 天用神秀的「时时勤拂拭」，第 30 天用慧能的「本来无一物」——月初还在天天擦镜子，月底才明白从来没有镜子。第 31 天起（continue_playing 加时）从第 1 天重转——字面意义上的轮回。

**释义（gloss）是灵魂**——不是佛学讲解，而是把偈子按进剧情里。示例：

> 第 10 天 ·「莫轻小恶，以为无殃。水滴虽微，渐盈大器。」——《法句经》
> 释义：每个红包都觉得自己很小。判决书上它们排成一列，叫「两万一千四」。

> 第 13 天 ·「譬如刀刃有蜜，不足一餐之美，小儿舐之，则有割舌之患。」——《四十二章经》
> 释义：52 块的红包是刀刃上那点蜜。尝过一次的人，不会记得舌头是怎么没的。

> 第 30 天 ·「菩提本无树，明镜亦非台。本来无一物，何处惹尘埃。」——慧能
> 释义：月初你还在天天擦镜子。月底你终于知道：从来没有镜子，也没有擦镜子的人。只有凌晨三点，亮着的那一块屏幕。

## 改动清单

### 1. 新文件 `src/data/gathas.ts`（内容核心）

```ts
export interface Gatha { verse: string; source: string; gloss: string; }
export const DAILY_GATHAS: Gatha[];      // 30 条，按上面的五幕分组
export const PROLOGUE_GATHAS: Gatha[];   // 4 条序章页脚
export const ENDING_EPIGRAPHS: Record<string, Gatha>;  // 10 个结局各一
export const TRIGGER_GATHAS: { industry_accept, industry_reject, risk_exposed, essay_close };  // 4 个触发点
```

**序章 4 页页脚偈**（每页正文后加偈语块）：
- 页一（现象）：「诸法因缘生，诸法因缘灭。」——「崩老头」不是凭空出现的，是这个时代的孤独和困窘一起把它生出来的。
- 页二（她）：「菩萨畏因，众生畏果。」——她盯着三千块的月供（果），没人告诉她利息滚起来那天（因）。众生总是先看见果。
- 页三（手段）：「由爱故生忧，由爱故生怖。」——五个哥哥要的不是那种事，是有人听他把话说完。可忧和怖，也从这声「哥哥」里生。
- 页四（选择）：「莫轻小恶，以为无殃。」——三十天里每一次开口都很小，像水滴。水滴虽微，渐盈大器。

**10 个结局各配一首结局偈**（在结局标题与正文之间渲染，善恶各有其报）：
- `end_verdict`（判决书）：「假使百千劫，所作业不亡。因缘会遇时，果报还自受。」——《大宝积经》｜释义：一页纸数完三十天。这些天没亡，它们只是在等。
- `end_exposed`（评论区）：「万般带不去，唯有业随身。」——古德｜释义：三个头像同时灰了的那晚，余额还在，别的都没带走。
- `end_deposit`（存折）：「一念贪起，百万障开。」——古德｜五位数压得住一个老人的血压吗？这道题她算了一夜。
- `end_family_man`（车库）：「仰天而唾，唾不污天，还污己身。」——《四十二章经》｜「别回，让她看见」——他护住了家，那口唾沫回头落在发消息的人身上。
- `end_confessed`（对不起）：「自悔其过，罪即消灭。」——《法句经》意｜半年后那条「带闺女去看海」的消息，比退回的红包重。
- `end_debt_free`（还完了）：「心无挂碍，无挂碍故，无有恐怖。」——《心经》｜结清那晚她没开香槟，只发了一句「李叔，早些睡」。
- `end_lied` / `end_numb` / `end_caught` / `end_broke` 各配（分别用「自诳诳人」「梦中人不知是梦」「缘尽则灭」「求不得苦」）。

**触发偈 4 条**：
- 买课进代聊群：「一即一切，一切即一。」——《华严经》｜一个号带三个号，三套话术四百个头像——这门生意把一念贪心复制成了流水线。
- 删掉姐妹私信：「知足之人，虽卧地上，犹为安乐。」——《佛遗教经》｜这一按，是这个月最干净的一笔。
- 穿帮事件：「万法皆空，因果不空。」——古德｜滤镜会掉色，定位会漂移，时间戳会说实话。评论区从不记错账。
- 终章收尾（编者按末段后）：「一灯能除千年暗，一智能灭万年愚。」——《六祖坛经》｜河床不会自己长出来。灯，得有人点。

### 2. 引擎接线 `src/engine/state-machine.ts`

- **晨钟**：`runMorning` 里账单 log 之后插入——
  ```ts
  const g = DAILY_GATHAS[(state.day - 1) % DAILY_GATHAS.length];
  log(state, 'gatha', `${g.verse}——${g.source}`, g.gloss);
  ```
  不消耗 RNG（不扰动种子确定性测试）；`line` 字段复用既有 `.log-line` 渲染，动态流与「流水」弹层免费获得展示。
- **穿帮**：暴露事件 log 后追加 TRIGGER_GATHAS.risk_exposed 一条 gatha log。
- **代聊课**：industry_reply 接受/拒绝两条路径各追加对应 gatha log。

### 3. 类型 `src/types/game.ts`

`EventKind` 联合加 `'gatha'`（动态流/弹层配色用）。

### 4. UI 渲染

- **`screens.tsx`** PrologueScreen：每页正文下渲染 `PROLOGUE_GATHAS[i]` 的偈语块（诗句/出处/释义三行，虚线分隔）。
- **`ending-screen.tsx`**：结局标题与正文之间加 `.ending-epigraph`（ENDING_EPIGRAPHS[endingId]）；`.essay-close` 段后追加 `.essay-gatha`（一灯偈）。
- **`main-screen.tsx`**：「这个游戏让你不舒服了？结束这一个月。」按钮下加一行小字：「苦海无边，回头是岸——这句偈不劝你，只是放在这里。」
- **`moments.ts`** 点滴渗入（各加 1 条 caption）：周老师习字「今日习字：观自在。三个字写了一上午——『观』字最难。」；钓友「放生了三两鲫鱼。放它的时候想：鱼也有家人。」

### 5. CSS `src/styles.css`

偈语家族样式（参照 `.ending-essay`/`.log-entry` 模式）：`.gatha-verse`（暖金 var(--warm)、letter-spacing、斜体）、`.gatha-source`（muted 小字）、`.gatha-gloss`（muted 13px）、`.prologue-gatha` / `.ending-epigraph` / `.essay-gatha`（容器：虚线顶边或卡片）、`.log-gatha { border-left: 3px solid var(--warm); }`。

### 6. 测试

- **门禁扩展**：`simulation.test.ts` 的禁词 blob（未成年/欺诈两处）加入 gathas.ts 全部导出新内容（佛法词与禁词零冲突，已核）。
- **新文件 `src/engine/__tests__/gathas.test.ts`**：月轮完整 30 条且诗句不重复、每条 verse/source/gloss 齐全；10 个结局 id 全有对应偈；引擎实测——new_game 后第 1 天有 kind 'gatha' 的 log（含 line 释义）、sleep 后第 2 天换第 2 偈、day 31 回卷第 1 偈（轮回）；买代聊课后 log 中出现华严偈。
- 既有 77 个测试不受影响（gatha log 不进 ledger、不消耗种子、不改任何数值断言）。

- 朋友圈/商店/照片/头像等 v2.2-v2.3 全部产出
