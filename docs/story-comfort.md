## 一、两条线，一个主题

| | 明线（v1.0.0） | 暗线（v1.1.0 舒适圈） |
|---|---|---|
| 讲什么 | **法**——她怎么开口、怎么穿帮、怎么落到判决书上 | **情**——这笔债是从哪个家里长出来的 |
| 载体 | 工作手机：五个"哥哥"、剧情链、红包、穿帮风险 | 常用手机：妈、阿凯、一部暖色的、素颜的手机 |
| 玩法 | 精力、信任、警惕、结局分支 | 免费聊天、日历剧情、无从选择的"听完" |
| 结局 | 由玩法决定：还清 / 崩盘 / 麻木 / 判决书…… | 不改结局——只交代来路 |

**主题句：亲情再伟大，也不能凌驾于法律之上。**

暗线的全部意义在于把这句话写实：

- 她堕落的每一个理由都是干净的——替妈还债、替死去的爸撑住这个家；
- 可判决书不读动机。催收电话、网贷合同、转账流水，每一张纸都比她的理由更硬；
- 而最终把"法"放在"情"前面的，恰恰是这条线里最爱她的人——妈。
  *"钱妈还，人得自己去。"*

明线与暗线的对立统一：**法是情的边界，情是法的代价。** 明线结算她的罪，暗线结算她的心。

## 二、人物小传

- **小满**（24 岁）：农历小满出生——妈说那天麦子正好灌浆。素颜一般，化妆后小美。
  幼儿园保育员出身，孩子哭了她会跟着掉眼泪。半年前妈住院，她在手机上点了三下，
  点出三万块。对同居男友恋爱脑——工作手机里她演别人的女儿，常用手机里她把自己
  交给一个不值得的人。
- **妈 · 王秀兰**（55 岁）：五年前丧夫。失业大半年后进家政公司做保洁，一户一户
  擦别人家的窗。每晚一通语音从不缺席。她不是不知道女儿的钱不干净——她从催收
  短信里查到还款账户，每个月往里打八百块，打了一个又一个"八百"。
- **爸 · 老周**（殁，享年五十余）：货运司机。谁张不开口，他就替谁跑，一辈子在
  "多跑一趟"里把家撑住。五年前替发烧的小徒弟顶夜班，心梗走在路上，手机里最后
  一条消息是发给小满的：「到了给你打电话」。旧按键机还在家里充着电，壁纸是一张
  小满没见过的全家福。
- **阿凯**（27 岁）：小满同居男友。自称灵活就业，主业是游戏里扮温柔男人哄中老年
  女性刷礼物（"崩阿姨"）。对小满甜言蜜语，对房租熟视无睹。他给小满的每一句情话
  的成本，都记在另一个女人的孤独账上。
- **兰姨**（52 岁，只在暗线中存在）：厂里退休，独居，儿子在外地。游戏里管阿凯叫
  小凯，处了半年"对象"，为他花了五万——她管那叫彩礼。她的儿子最后报了案。

### D28 阿凯的崩坏（双分支，殊途同罪）

- **纵容线**（一直给他钱）：D28 他失联。傍晚同城群转发警情通报：以恋爱名义骗取
  多名中老年女性财物，涉案十一万余，含退休女工兰某养老钱五万——通报里管那叫
  "彩礼"。配图灰卫衣与门把手上的裙子是一套。他给小满转的 52 块"生日补过红包"
  停在半路，那笔流水记在**案卷第 9 页**。
- **分手线**（拒他要钱两次）：他卷走活命钱拉黑小满，第十天，同一份通报——报案人
  是兰姨的儿子：*"我妈管他叫小凯，管那五万叫彩礼。"* 小满被卷的钱在证据清单
  第七项，备注两个字：赃款。
- **共同落点**：他举报过她（报复线），也骗过兰姨。法没因为他的举报饶过她，也没
  因为她的沉默放过他。**谁的账，最后都有人来收。**

## 四、法与情的咬合点（暗线如何填明线的坑）

1. **月供 1500 的来路**：明线只说"网贷下月到期"。暗线 D9 交代：妈每月还 800，
   但利息比她擦得快——窟窿原封不动，剩下的 1500 仍要小满去"崩"。她的每一次
   开口，都是在偷妈擦窗的时间。
2. **三万块的去向**：序章说"半年前母亲住院，她点了三万块"。D4 补全：胆手术、
   三床、锅炉房的窗；D26 补全：妈早从催收短信里知道了账户。
3. **警察上门的伏笔**：明线举报/判决书结局在暗线 D26 被预先"合法化"——妈亲口
   把"去派出所说清楚"说在了所有责备前面。玩家此后再遇到警察结局，会想起那句话。
4. **崩阿姨 ↔ 崩老头的镜像**：阿凯与兰姨，是小满与五个"哥哥"的镜子。D7/D23
   两次点破，D28 收束——同一张手法，同一个下场，情不能豁免法。

## 五、结局矩阵（暗线视角）

| 明线结局 | 暗线补笔 |
|---|---|
| 月底还清（win） | 账本清了，但本子上还有下一页——债清了，人还没"回来" |
| 崩盘（broke） | 妈的八百还在打，利息还在长；D30 的排骨汤还温着 |
| 麻木（numb） | 她对"哥哥"麻了，可 D9 那个红皮本子她合不上 |
| 判决书（verdict） | 判决书不读动机。D26 那句"人得自己去"已经把这条路提前铺好了 |
| 警察上门（暗线触发） | 录口供那天的旁白——她躲过了阿凯，躲不过自己签下的合同 |

## 六、话术纪律（暗线红线）

- 暗线台词与明线话术同一审计口径：全库零重复、称呼不越界、无可操作细节；
- 催收/网贷的描写止于"电话、短信、风险提示"三个词，不展示任何话术与流程；
- 妈的方言感、爸的沉默感、阿凯的怯与狠，全部通过称谓与节奏体现，不靠标签。
