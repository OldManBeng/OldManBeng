# 03 · 实施记录 · 工作手机对比度修复（视觉协议第 2 轮）

> 对应诊断：`00-视觉诊断报告-工作手机.md` 的三处 🔴 红线（全部为 WCAG AA 实测不达标）。
> 本轮先修红线；中低severity 项（间距双轴、字阶双定义等）按协议待基准确认后另行实施。

## 修复 1 · 主按钮白字 3.65 → 4.81 ✅

- 方案：新增 `--accent-fill: #0A70DC` **只作实心按钮底**；`--accent` 本色保留作
  文字/链接/描边（深底上 5.52 ✓——若全局加深反而会把链接文字拖到 4.18）。
- 影响面：「天黑了」「开始今天」「找他说话」、小卖部全部购买按钮（`.btn.primary`）。
- 实测：白 on #0A70DC = **4.81** ✅ AA（候选 #0A78E8=4.32❌、#0664C8=5.73 过深）。

## 修复 2 · 进度条标签 2.2-3.1 → 4.7-5.8 ✅

- 根因有两层：①填充是 60-62% 半透明色，文字被罩在色膜下；②文字本体是 66% 灰。
- 修复：四条填充改**实色加深**（白字实测：精力 #0864C0=5.37 / 麻木 #7C55A8=5.18 /
  信任 #1E7E36=4.71 / 警惕 #C0332B=5.14）；标签由 muted 灰提为全白 `--label`。
- **层级修复**：绝对定位的填充 span 原本绘制在文字上层（半透明时罩住文字、实色时
  完全盖死）——`.bar { isolation: isolate }` + `.bar span { z-index: -1 }` 把填充
  压回背景层、文字提到最上。
- 实测对比（修复后）：白字 on 实色填充 = 4.71-5.37 ✅；on 空轨道 = 11.4 ✅。

## 修复 3 · 钱包支出语义色失效 ✅

- 根因：`.wallet-summary strong`（0-1-1）的 `color: var(--warm)` 以来源顺序与特异度
  压过 `.pos/.neg`（0-1-0）——支出恒为金色。
- 修复：新增 `.wallet-summary strong.pos/.neg`（0-2-1）——收入绿 #30D158（8.24 ✓）、
  支出红 #FF453A（4.89 ✓），余额/进度保持金色。暖色主题钱包共用此规则同步受益。
