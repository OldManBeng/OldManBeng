# 01 · 舒适圈（常用手机）设计基准

> 协议：《视觉优化协议.md》第 2 阶段产出（⭐核心阶段）。
> 所有对比度均由 `contrast-check.js` 实测（WCAG 相对亮度公式 + rgba 合成），
> 非「感觉够」——包括**推翻现状注释里两处失实的声明**（见 A-0）。
> 本阶段不修改任何网站文件；逐项确认后才进入第 3 阶段。

## A. 色彩系统

### A-0 实测纠错（先说结论）

| 声明（现状注释） | 实测 | 判定 |
|---|---|---|
| 「白字 on 主色 #C2620E = 4.6:1」（styles.css:1846） | **4.16:1** | ❌ 失实——主 CTA 白字不达 AA |
| 「n5 辅文 4.9:1」 | n5 on n0 = 4.77 ✅；**on n2 = 4.00 ❌；on n1 = 4.40 ❌（11px 小字）** | ⚠️ 部分失实 |

### A-2 语义色使用规则（对应诊断 #4）

事件卡左侧彩条 + tag 色四分——把「信 / 钱 / 冲突 / 剧情」在视觉上分开：

| 事件类型 | 彩条/强调色 | 语义 |
|---|---|---|
| mom_gift / bf_packet（收钱） | `--c-gold` | 温情的钱——和「灯笼金=钱」的站级语义一致 |
| bf_demand（要钱） | `--c-danger` | 代价 |
| quarrel（吵架） | `--c-rose` | 感情冲突 |
| story / auntie_intro 之外的纯聊天卡 | `--c-story` | 暗线剧情：只能听完的「信」 |

### A-3 夜色档完整色板（对应诊断 #2，L1）

夜间不再只染两个元素，改为**一组成体系的覆盖规则**（全部走新令牌）：

- 页面：现有靛蓝 radial 罩保留（置于内容之后，卡片自身不透明不受影响）；
- day-chip / phone-tag：改实底 #2E3350（10.45 ✅），废 `#AAB2D6`（1.17 ❌）→ #C9CFEA；
- 速聊行/事件卡在夜里的禁用文案、关系条等**透明底元素**：夜间统一把
  n5 级文字升到 n6（实测透明底 + 夜罩下 n5 = 2.99 ❌，n6 = 5.19 ✅）——
  一条 `.comfort-night` 作用域规则解决，不逐个改组件；
- 气泡在夜里保持白/暖绿不变（聊天是「家里的灯」，夜里不该变冷）。

## B. 字体系统

| 项 | 提案 | 依据 |
|---|---|---|
| 字阶合并 | 保留 `--c-fs-*` 6 档为唯一口径；`--fs-7/--fs-8` 钉值保留但注释升级为「冷色主题兼容层，暖主题禁用」 | 消除双口径漂移（诊断 F2） |
| 功能标签最小字号 | 11px → **12px**（`--c-fs-caption`）：关系条、简报 label、事件 tag、语音秒数全部升档 | 11px × 4.77 边缘；12px + n6 全场 ≥4.8 |
| 语音秒数 | `opacity 0.7` 去掉，色 n5→n6 | 现状 ≈3.3 ❌ → n6 on n0 = 8.26 ✅ |
| 数字等宽 | `tabular-nums` 扩展到事件卡金额、钱包 summary、镜像行数字 | 与 HUD/秒数同口径 |
| 楷体范围 | 不变（叙事文本专属，功能 UI 不用楷体） | 现状正确 |

## C. 空间系统

间距全部收敛到 4px 刻度（现状 6/10/12px 裸值清零）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--c-s-1..6` | 4/8/12/16/20/24 | 唯一刻度 |
| 卡内边距 | 统一 **12px 16px**（`--c-s-3 --c-s-4`） | event-card / day-row / verse / police-card / mirror 五种卡对齐 |
| 卡间距 | 12px；组间 20px | 简报内分组呼吸（对应诊断 L2） |
| 行内 gap | 8px 或 12px，废 10px | rel-strip / day-row / cec-actions |

## D. 形状与层次

- 圆角三档不变（8/12/16 + full）；
- 阴影两档不变（`--c-shadow-1/2`）；
- **边框规则明确化**：实线 = 结构边界（卡面）、虚线 = 叙事插页（mirror/verse/rule/father-bio）——现状已隐含此规则，写成文防漂移；
- 事件卡层次：彩条 3px + tag 胶囊同色 14% 底，剧情卡另加 1px `--c-story` 30% 描边（「信封」感）。

## E. 组件视觉规范

**按钮四态（暖主题专属）**：

| 态 | 规格 |
|---|---|
| 主（filled） | 底 `--c-accent`（#B85A0A）白字，hover 加深 8%，active scale(0.98)，disabled = 现状虚线灰 |
| 次（默认描边） | 透明底 + `--c-line` 边 + n7 字，hover `--c-hover` |
| 弱（muted-btn） | 现状保留但加图标语义：婉拒/晾着他/先不回的按钮文字前统一走 n6 色（不是纯灰），代价提示用括号文案现状保留 |
| 禁用 | 虚线 + n5（大字号场合）/n6（12px 功能场合） |

**组件统一规则**：
1. 剧情卡 `📨` emoji → **SVG 图标**（icons.tsx 新增 `letter` 信封图标，同源 1.6 描边口径）——修复诊断 #1 红线违规；
2. 语音条：秒数 12px n6；播放三角/声波动画不变（已是示范项）；
3. 关系条（rel-strip）：meter 高 4px 不变，label 12px n6；
4. 钱包 summary：金额 tabular-nums + pos/neg 语义色不变；
5. 「开始今天」弹窗：分组间距按 C 节刻度重排（余额格 12 / rule 组 20 / 经文 12），不加内容。

## F. 布局规范

1. 单列 420px 不变；HUD/底导航玻璃化不变（与工作手机同构是刻意的）；
2. **夜间态覆盖**（A-3）是本基准唯一的布局级新增——不改 DOM 结构，纯 `.comfort-night` 作用域 CSS；
3. 360px 语音条：`min-width: 92px → 84px`，头像 30px 不变，气泡 `max-width: 78% → 74%` @360px 媒体查询一处。
