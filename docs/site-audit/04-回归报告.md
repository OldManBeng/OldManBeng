- 375/420px：单列布局未动，无新增溢出点；360px 新增语音条/气泡让宽规则。
- 截图走查已补录（§6）：昼/夜 × 五模块实景截图确认无布局破碎。

## 3. 跨浏览器
- 新增 CSS 仅用到 `color-mix`（既有代码已大量使用，基线一致）与
  CSS 自定义属性——无新兼容风险。Safari/Firefox 不另行处理。

## 4. 深色模式
- 本游戏即「主题即叙事」（冷/暖两套固定主题），无系统深色模式跟随——不适用。

## 5. 交互回归（协议红线：交互逻辑冻结）
- **DOM 结构零改动**（唯一 TSX 改动：`📨` → `<Ico name="letter"/>`，同一位置同一语义）；
- 事件绑定、dispatch、数据流：零改动（git diff 可证）；
- 动画：voice-wave / phone-flip / reduced-motion 均未触碰；
- **测试**：`npm test` 20 文件 **288 用例全部通过**（含 dialogue-audit 常驻审计、
  comfort 话术红线）；`npm run build`（tsc strict + vite）通过。
