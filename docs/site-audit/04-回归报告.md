## 2. 响应式检查

- 未做真机/浏览器截图对比——本环境无浏览器工具，建议人工在

  事件卡四色 → 剧情卡信封图标 → 360px 聊天」，约 3 分钟。

## 3. 跨浏览器
- 新增 CSS 仅用到 `color-mix`（既有代码已大量使用，基线一致）与
  CSS 自定义属性——无新兼容风险。Safari/Firefox 不另行处理。

## 4. 深色模式
- 本游戏即「主题即叙事」（冷/暖两套固定主题），无系统深色模式跟随——不适用。

- **测试**：`npm test` 20 文件 **288 用例全部通过**（含 dialogue-audit 常驻审计、
  comfort 话术红线）；`npm run build`（tsc strict + vite）通过。
