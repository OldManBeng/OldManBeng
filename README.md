# 凌晨三点，哥哥

一个以**女性视角**体验「崩老头」现象的严肃现实向聊天经营游戏（v2.0：五模块 + 50 人库 + 计划偶遇 + 双向联系 + 性格亲和系统 + 人设档案）。

> 「崩」在北方方言里意为哄骗、套取。「老头」不是真正的老人，而是对中年男性的戏称——
> 指年轻女性以情感陪伴、暧昧互动为手段，向情感空虚的中年男性小额高频索取钱财的灰色行为。
> 本游戏是这个现象的批判性演绎：你亲自动手，游戏替你记账——钱，和代价。

## v2.0 大改版：五个模块

底部五按钮导航，分别对应这门生意的五个面：

- **今天**——每日计划（决定今晚在哪、遇到谁）+ 他来找你的卡片（回他/划掉）+ 白天/深夜的名单 + 事件流。
- **通讯录**——已认识的全部老头（主五人 + 计划偶遇入册的库目标），拉黑的沉底，附"还有 N 个人在这座城里"。
- **钱包**——余额 / 收入 / 支出 / 目标进度 + 全部流水（日摊账单、红包、礼物、计划、事件每一笔都记账）。
- **聊天记录**——每场对话归档（容量封顶 40 场），点开可展开整场 transcript。
- **人设**——女主头像 6 款 / 自称年龄 4 档（20/24/28/32，全部成年）/ 性格 4 种 / 朋友圈自拍 4 种，
  全部影响他的话术与好感走向；换自拍会刷新发布日，最近 3 天内"他来找你"概率大增。

## 游戏循环（30 个游戏日 ≈ 1 小时）

1. **白天（上午）**：账单自动扣（每天 53 元）、2d6 掷随机事件；**选一个计划**——
   去公园/棋摊/广场舞容易偶遇新老头（解锁进通讯录），宅家省精力但遇不到人，代驾蹲单给 120 元但风险 +3。
2. **入夜**：每晚精力 16 点，一场聊天 4 点，**最多聊 4 场**（白天 2 + 深夜 2）。深夜在线的老头随你挑——精力就是排程。
3. **聊天**：主五人各 10 套闲聊话术（近 3 套去重轮换，不再每次同一套）+ 独立四阶段剧情链（8 个故事节点，一晚推进一个）；
   库目标无剧情链，靠原型话术组（每原型 5-9 套）吃饭。对话逐字打字机节奏，可点「不等了」直接看完。
   话术里带 `{selfie}/{age}/{trait}` 占位符——他的台词会念到你朋友圈那张照片、你自称的年龄、你的人设。
4. **他来找你（双向）**：发新自拍后 3 天内，他大概率主动私聊（按情感缺口加权）；信任高、断联、发工资日的也会主动找。
   一天最多攒 2 条，两晚不回应就过期。**回他**=开一场他起头的会话；**划掉**=信任 -3、断联 +1（孤独的人记得已读不回）。
5. **开口要红包**：warming 前开口=当冒犯；钱包冷却 3 天；概率 `0.25 + 信任×0.5 − 警惕×0.5 (+孤独加成)`；
   红包分层：奶茶钱 10-50 → 零花钱 50-88 → 心意 88-520（慷慨型 ×1.4）。每笔钱进钱包流水。
6. **性格亲和系统**：每场对话开场结算一次——`性格×原型`矩阵（4×9，有正有负）+ `年龄×情感缺口`矩阵。
   嘴甜哄得住丧偶老师（trust+2），却让建材老板掉价（trust-1、wariness+2）；高冷让工程师更放心，却把丧偶老师推远。
   没有万能人设——选谁、怎么演，决定了涨谁的好感、失谁的信任。
7. **麻木与休息**：表演亲密每场 +4-8 麻木（日上限 8，flirty 也吃额度）；**一晚不聊天缓 -5**——
   歇一晚是真实取舍：少挣一场的钱，换回 5 点麻木。满场演出 30 天必然走进麻木结局。
8. **朋友圈穿帮风险 + 产业化分支**：多线经营风险每天 +7%/条；风险 ≥40% 后每天 25% 概率穿帮（被看见警惕 +30、全员 +6）。
   姐妹的"课程"：转 300 进代聊群（信任+5/天、风险+3/天、麻木+2/天），开口累计 ≥8 次 → **判决书结局**。

## 安全门（测试强制）

- 全部 50 个老头目标 35 岁以上；女主自称年龄档位 20/24/28/32 全部成年
- 文案不含未成年人相关内容、不含可实操的诈骗细节（无卡号/验证码/收款渠道话术）
- 每个要钱选项必带信任/警惕代价——游戏内没有"免费的钱"

## 架构（复用《华丽人生2》模式）

```
src/
├─ types/        全部类型 + scripts-registry(按老头的脚本注册表)
├─ data/         纯数据：constants(带注释的平衡数值) / targets(主五人) / target-library(库45人)
│                plans(8计划) archetype-packs(4原型话术组) main-packs(主五人各10套话术+incoming台词)
│                script-registry(内容注册表——加老头只加数据不碰引擎)
│                scripts(李) zhou-script(周) wang-script(王) hao-script(豪) chen-script(陈)
│                events(2d6 事件表) / endings(10 结局) / personas(4人设)
├─ engine/       纯函数 dispatch 状态机(时段/计划偶遇/他来找你/亲和矩阵/麻木日额度/归档/流水/穿帮/产业化)
│                + 聊天引擎(要红包判定/人设匹配/红包分层/话术组去重/占位符替换)
│  └─ __tests__/ balance / simulation(5目标自动跑局+产业化线) / v2-systems(22条新系统回归) / safeguards
├─ store/        Zustand 薄封装 + localStorage 存档（v1→v2 migrate 补全字段）
├─ components/   程序化 SVG 头像(6款可选+表情随警惕) / 五模块导航 / 计划面板 / 人设档案
└─ utils/        seed RNG / formatMoney / Web Audio 合成音效(零音频文件)
```

- `dispatch(state, action)` 纯函数引擎，状态全 JSON 可序列化（存档=序列化 state）
- 零美术/音频资产：SVG 程序化头像 + Web Audio 合成音效
- 数值全部集中在 `data/constants.ts`，每项带设计意图注释
- `scripts/ending-distribution.ts`：多策略 × 60 种子的结局分布校准脚本

## v2.0 改版要点

- **精力 16/4**：每晚最多 4 场对话（白天 2 + 深夜 2），同时经营 4 条线才转得开
- **50 人老头库**：主五人剧情链 + 45 人偶遇库（9 原型 × 5 人），以计划解锁入通讯录
- **每日计划**：8 个计划决定今晚在哪、遇到什么原型、花多少精力/钱/风险
- **双向联系**：他也会主动找你（新自拍/断联/发工资日触发），回他或划掉都有代价
- **性格亲和矩阵**：4 性格 × 9 原型 + 4 年龄 × 4 情感缺口，每场对话结算正负漂移
- **人设档案模块**：头像/年龄/性格/朋友圈自拍可编辑，全部影响话术与好感
- **话术组去重**：近 3 套用过的轮换，不再"每次都触发相同话术"；占位符替换让他的台词念到你的资料
- **钱包流水 + 聊天归档**：每一笔钱记账、每场对话存档（容量封顶 40），全站点可查
- **麻木日额度 + 休息恢复**：一天最多 +8 麻木（flirty 也吃额度），一晚不聊缓 -5

## v1.1 全项目 review 修复

- **断联惩罚误判**：每天早上都给"昨天聊过的人"记断联（信任-4/-8）——改按 `lastChatDay` 判定，天天聊的人不再被惩罚
- **存折结局不可达**：`end_deposit` 要求的 flag 没有任何选项会设置——周老师存折开口选项已接线（且只在要钱**成功**的当晚落下 flag）
- **要钱的剧情 flag 在掷骰前就生效**："拿到了存折"不该发生在她被拒绝的那晚——所有 `isAsk` 选项的 setFlag 延后到 ask 成功分支
- **事件 effect 死类型**：`trust`/`mood` 声明了但引擎不处理——补上 trust（支持指定 targetId）与 conscience；妈妈电话的占位效果改为良心 +3
- **音效接线**：发话用 playSend、红包气泡用金币声、开口被拒/被拉黑/新的一天分别接线（原先五个音效只有消息声在响）
- **React 副作用卫生**：playEnding/loadMutePref 从渲染体挪进 useEffect
- **文案与硬编码**：开局提示"三个人"改为五人；精力门槛/文案里的裸 `4` 全部换 `CHAT_SESSION_COST` 常量
- **测试补强**：ask-flag 成功门控、每日聊天免断联惩罚、结局 flag 可达性守卫（防"死结局"复发）、豪/陈链纳入要钱后果检查
