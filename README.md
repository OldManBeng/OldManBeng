# 情感反诈模拟器 v1.1.0

> 原名《凌晨三点，哥哥》——名字先说清楚这是反诈题材，故事仍然叫凌晨三点。

一个以**女性视角**体验「崩老头」现象的严肃现实向聊天经营游戏。

> 「崩」在北方方言里意为哄骗、套取。「老头」不是真正的老人，而是对中年男性的戏称——
> 指年轻女性以情感陪伴、暧昧互动为手段，向情感空虚的中年男性小额高频索取钱财的灰色行为。
> 本游戏是这个现象的批判性演绎：你亲自动手，游戏替你记账——钱，和代价。

这不是教你骗人的游戏。这是一部让你坐在骗子的位置上，感受 30 天，
然后自己想明白的游戏。全片没有一句可模仿的话术——能教的只有一件事：
屏幕那头的人，为什么会上当。（发行口径全文见 [docs/release.md](docs/release.md)）

## 第二阶段 v1.1.0：舒适圈（常用手机）

v1.0.0 发布之后的新篇章。她叫**小满**——农历小满那天出生；素颜一般，化妆后小美；对男朋友恋爱脑。崩老头的那部是工作手机，这部，是常用手机。

- **切换常用手机**：人设浮层「变更人设」之后新增入口（常用手机顶部可切回）。整体配色换成暖色系——温情是暖的，算计是冷的，手机先替你分好类。同一根 30 天时间轴，两个世界互不可见，只有你两头都在。
- **一套全新的五菜单**：今天 / 通讯录 / 朋友圈 / 聊天记录 / 钱包——同名不同套。
- **通讯录（3 人）**：爸（几年前过世，一直置灰；点开是一段纪念，忌日当天常用手机替你记着）、妈（王秀兰 55 岁，失业后在家政公司做保洁）、同居男友阿凯（27 岁，游手好闲沉迷游戏，在游戏里"崩阿姨"赚小钱，对小满甜言蜜语）。
- **妈的温情（进活命钱）**：她隔三差五嘘寒问暖，发工资了就给你转 150-300 生活费——**要 / 不要**影响家庭关系；要了进活命钱（正向现金流）。
- **阿凯的红包（进活命钱）**：他"崩阿姨"赚到钱会分你一半（52-188）——**要 / 不要**影响感情。
- **阿凯要钱（从债中扣）**：会找你要钱（200-600），不给就威胁——**给 / 不给**：给了先扣活命钱、**扣不动的部分记到这个月的债上（崩老头进度被直接拖慢）**；不给触发连锁——累计拒绝 ≥2 次或感情冰点 → **分手**（他偷偷发展的游戏女友曝光，卷走活命钱全部余额并把你拉黑）；否则可能触发**报复**：扬言举报（穿帮风险 +25）、一定几率**警察上门录口供（当天精力清零，游戏进程被打断）**。
- **话术**：母亲 11 套 / 男友 11 套日常话术 + 各 3 组事件话术（全库台词零重复，测试强制）；每套 = 他的话 + 她的选项 + 每个选项的回应，同套内上下文天然连贯；第 14 天埋着他那句说漏嘴的"真心话"（分手伏笔）。
- **语音条气泡**：熟人聊天全是语音——气泡显示微信式「▶ 语音 xx″」条（按文本长度确定性派生秒数），下方才是真文字。游戏没有真语音，只是显示效果。
- **舒适圈朋友圈**：励志向语录 + 晒家庭幸福 + 晒恩爱 三类主打；妈必点赞评论（她一条条看），男友抢着互动；他们偶尔自己也发。没有穿帮风险——这边的人本来就都认识彼此。
- **聊天不耗体力**：舒适圈的聊天免费——那是她的生活，不是生意。
- **对比叙事（本阶段锚点）**：家人的温情关怀 vs 外人的冷漠算计——妈的钱**没有来源字幕**（哥哥们的钱每一分都标着价格："这笔钱，是他今晚多跑的四单"）；镜像行点破两台手机的同构台词（老李问"丫头吃了吗"和妈问"满满吃了吗"，一句后面是饭，一句后面是账）；切机旁白、钱包"两本账"、收钱/威胁/分手时的对照旁白全部落进日志与界面。

## 核心循环（30 个游戏日 ≈ 1 小时）

1. **白天（上午）**：「新的一天」简报弹框先落地——日期、余额/还差/风险三格、账单与随机事件逐行浮现、晨钟偈收音。账单自动扣（每天 53 元）、2d6 掷随机事件；**选一个计划**——
   去公园/棋摊/广场舞容易偶遇新老头（解锁进通讯录），宅家省精力但遇不到人，代驾蹲单给 120 元但风险 +3。
2. **入夜**：每晚精力 16 点，一场聊天 4 点，**最多聊 4 场**（白天 2 + 深夜 2）。深夜在线的老头随你挑——精力就是排程。
3. **聊天**：主五人各 10 套闲聊话术（近 3 套去重轮换，不再每次同一套）+ 独立四阶段剧情链（8 个故事节点，一晚推进一个）；
   库目标无剧情链，靠原型话术组（每原型 5-9 套）吃饭。对话逐字打字机节奏，可点「不等了」直接看完。
   话术里带 `{selfie}/{age}/{trait}` 占位符——他的台词会念到你朋友圈那张照片、你自称的年龄、你的人设。
4. **他来找你（双向）**：发新自拍后 3 天内，他大概率主动私聊（按情感缺口加权）；信任高、断联、发工资日的也会主动找。
   一天最多攒 2 条，两晚不回应就过期。**回他**=开一场他起头的会话；**划掉**=信任 -3、断联 +1（孤独的人记得已读不回）。
5. **开口要红包**：warming 前开口=当冒犯；钱包冷却 3 天；概率 `0.25 + 信任×0.5 − 警惕×0.5 (+孤独加成)`；
   红包分层：奶茶钱 10-50 → 零花钱 50-88 → 心意 88-520（慷慨型 ×1.4）。每笔钱进钱包流水，**话术红包与实际落账严格一致**（引擎同步记账）。
6. **性格亲和系统**：每场对话开场结算一次——`性格×原型`矩阵（4×9，有正有负）+ `年龄×情感缺口`矩阵。
   嘴甜哄得住丧偶老师（trust+2），却让建材老板掉价（trust-1、wariness+2）；高冷让工程师更放心，却把丧偶老师推远。
   没有万能人设——选谁、怎么演，决定了涨谁的好感、失谁的信任。
7. **麻木与休息**：表演亲密每场 +4-8 麻木（日上限 8，flirty 也吃额度）；**一晚不聊天缓 -5**——
   歇一晚是真实取舍：少挣一场的钱，换回 5 点麻木。满场演出 30 天必然走进麻木结局。
8. **朋友圈穿帮风险 + 产业化分支**：多线经营风险每天 +7%/条；风险 ≥40% 后每天 25% 概率穿帮（被看见警惕 +30、全员 +6）。
   姐妹的"课程"：转 300 进代聊群（信任+5/天、风险+3/天、麻木+2/天），开口累计 ≥8 次 → **判决书结局**。

## 五大模块

底部五按钮导航，分别对应这门生意的五个面：

- **今天**——每日计划（决定今晚在哪、遇到谁）+ 他来找你的卡片（回他/划掉）+ 白天/深夜的名单 + 事件流；人设档案收进此页，「变更人设」按钮唤起全屏浮层。
- **通讯录**——已认识的全部老头（主五人 + 计划偶遇入册的库目标），免打扰（=玩家拉黑，可逆）的置底沉底，附"还有 N 个人在这座城里"。
- **钱包**——余额 / 收入 / 支出 / 目标进度 + 全部流水（日摊账单、红包、礼物、计划、事件每一笔都记账，同一精度、同一笔只记一次）。
- **聊天记录**——每场对话归档（容量封顶 40 场），点开可展开整场 transcript（实时对话与历史归档渲染一致）。
- **人设**——女主头像（每人设 10 款）/ 自称年龄 4 档（20/24/28/32，全部成年）/ 性格 4 种 / 朋友圈自拍，
  全部影响他的话术与好感走向；换自拍会刷新发布日，最近 3 天内"他来找你"概率大增。

## 剧情与人物

**主五人剧情链 + 老头人生线**。五个主角各有四阶段剧情链（8 个故事节点 + 分人设高潮回应），同时他们的人生按**日历**推进——不看信任度、不看聊没聊，日子到了就发生（不耗 RNG）：

- 周老师：忌日摆两只茶杯 → 书法班场地费涨三百 → 深圳的包裹 → 复查缴费单压在"宁静致远"那页 → 儿子又不回家 → 《劝学》长卷 → "存折放着也是放着"
- 老李：体检报告"还能跑十年" → 闺女十五岁生日（信任 ≥30 他真的来问礼物建议）→ 连排七天夜班 → 变速箱渗油"先开着" → 同行老周心梗走了 → 抚养费找妹妹周转；第二卷加深：闺女三秒语音/腰片
- 王总：家长会坐最后一排 → 老婆查账、转账备注改"零花钱" → 车库睡着七个烟头 → 街上又空两间铺子 → **教育金这个月没存上**；第二卷：撤回的"支持"/班级群的"收到"
- 阿豪：报废主板拆旧顶新 → 橘猫病了八百三（拿够 200 元后变体："用便宜点的方案"）→ 发小婚礼锁门 → 涨租 → 月底净亏两千二；第二卷：碰翻奶茶的猫/对面自习室
- 陈工：掐表记下 21 分 47 秒 → 机床厂论吨卖、台钳多擦一遍 → 自费打样 → 圣诞第三年不回来；第二卷：±0.02 公差/徒弟的新车/牛皮纸袋

每个节点三层文案：`text`（基准）/ `costText`（她已拿走 ≥ costFrom 元时——同一件事被她的账改写的那一面）/ `blockedLine`（他删了她，日子照过）。派发通道复用现有系统：晨报"他的今天"行、他的朋友圈（配场景图）、他来找你（"他今天有事想跟你说"）。

**节奏日**：Day 5 妈的相册 / Day 10 群里出事 / Day 15 电梯镜子（麻木 ≥40 才看得见）/ Day 20 半程账单（插值真实红包数）/ Day 25 倒计时——前三个带**决策卡**（两个选项都有代价，过夜落锤）。30 天全睡穿不可能：每天至少 1 条 life/beat 行（测试断言）。

**代价呈现四触点**（`src/data/cost-narratives.ts`）——男性玩家在这一帧里看见的是：**钱是从哪个具体的人的哪件具体的事上来的**：

1. 红包来源字幕：每笔红包到账即字幕——"（这笔钱，是他今晚多跑的四单。）"
2. 开口旁白：每人 6 条（Day 8 起轮换）——全部从人生线长出来
3. 主动转账旁白：他主动转钱（没人开口要过）时，日志带他的日子——"转完那句'拿着买点热的'，他就收车了"
4. 收工账：睡前"今天进账的钱，在他们的账本上各有名字"

**库人物也是人**：45 人各有 2 条个人进场白与 1 条个人 incoming（从 bio 长出来：监控室雷子的四十块屏幕/北门老翟的高架吃灰/残局余师傅没解开的残局），第一次聊天优先派发，之后回落原型组（同原型开场白不同的断言在测试里）。

## 人设与话术系统

- **人设不只是皮肤**：四个人设各有专属剧情节点（`onlyPersona` 门控）——知心姐姐能走进老李"只对姐说"的那间屋，文青能接到周老师不敢念的下阕，御姐能听到王总说漏嘴，学妹能拿到 13 号机。选错人设，这些房间你一辈子进不去。结局屏有「这个月，你演的是谁」四段人设各自的月度尾声；人设×情感缺口命中每场 +1 信任、冲突每场 +1 警惕。
- **同一句话，人设嘴里不同说法**（`personaText`）：开口要钱、坦白、嘴硬这些重场戏（含全部剧情链开口选项），四个老伙计听到的是四句不同的话术；五主角 × 四人设另有**专属开场白池**（60 条），55% 概率优先派发。
- **话术语境系统**：昨晚聊过的话题（每个话术组带 topic 标签），今晚他可能"接昨天的话"（recall 池，全部自包含收束句）；信任 ≥50 后开场白换更亲近的 `greeting_close` 池；近 3 条开场白跨场去重，话术组去重窗口 10——60 套库连玩 10 晚不重样。
- **话风卡**（`data/voice-cards.ts`）：每个角色一张打字习惯宪法——打字风格/口癖/表情媒介/单条长度/主动性/网感/必聊话题/对冷淡的反应/风格锚点。主五人各一张（老李空格断句无标点、周老师书面句号、王总逗号一逗到底+哈哈、阿豪极短句+6、陈工编号体），45 库人物按原型五张。
- **气泡合规**：台词 = 消息文本，一个气泡一行——引擎支持 ｜ 连发分隔、真实时间戳、`[图片]/[语音 12"]/[撤回了一条消息]` 合规标注；第二人称评述（（他笑了。）类，本作自 v1 的标志性叙事声音）以**独立旁白气泡**呈现（居中、斜体、灰、无气泡底），整段全括号的段落按叙事层归 narrator。
- **常驻审计回归**（`dialogue-audit.test.ts`）：50 剧本 / 949 套话术 / 2738 条开场白 / 2191 个选项逐条机器检查——称呼越界（他的台词对她的称呼必须属于本剧本）、时间戳与作息一致、玩家选项人设锁词、非开口选项必有回应词、开场白与选项不逐字重复、占位符白名单、各台词池规模下限、库话术叙事层红线。话风违例直接挂测试。
- **越界节奏与冷淡三态**（退/缠/找补）由既有机制承载：ask_fail 池即"找补"话术（装糊涂/玩笑化/委屈/道德绑架各成一格）、进场白需现实借口、silent_warning 即"缠"。

## 朋友圈：活的社交面墙

- 发圈当场就可能有人来互动（最多两个反应）；近 3 天内的圈每天早上继续发酵，不同的人陆续点赞、留评——同一个人对同一条圈只互动一次。
- 评论有 45% 概率是在说这张照片本身（照片专属评论池），其余按情感缺口出话；疑心重的人当场/次日都可能留下不太客气的话；加了微信就会看你的圈（不必先聊过天）。评论区 ≥3 人留言依然推高穿帮风险。
- 照片/自拍带**变体系统**：发送/发圈/发人生线动态时按 `pickVariant(出现key)`（FNV-1a 纯函数）派生同主题随机变体——不消耗主 RNG 流，同 key 必同图、跨渲染站点稳定，旧存档零迁移。

## 视觉资产：文生图 PNG 管线

全部内容型图像由内网 ComfyUI（z_image_turbo GGUF 工作流）生成，固定种子表可复现；程序化 SVG 渲染器全部保留为 **404 兜底链**（`<img>` onError 自动回退），运行时不依赖资产可用性。

- **女主头像**：每人设 10 款同脸不同穿搭（4 人设 × 10 款 = 40 张，`public/avatars/{personaId}/avatar-{1..10}.png`，#1 = 该人设默认脸）；avatarId 语义为「当前人设内 1-10」，切人设重置为 1，头像选择网格按人设过滤（带装扮名 label）。
- **老头头像**：`public/oldmen/{slug}.png`（256×256），50 个目标按 (archetype, shotType) 归并为 11 款去重造型（6 真脸 + 5 照片型场景：方向盘照/保安帽照/钓鱼照/精致摆拍）；生成底座是「直男手机摄影」（前置硬闪光/T 区油光），与女主美颜自拍成对照；下线态 blocked 用 CSS 灰度复刻。
- **场景照片与自拍**：17 张老头发来的照片（`public/photos/`）+ 8 张女主朋友圈自拍（`public/selfies/`），768×576 4:3 横构图；写实/插画双轨（带人的写实派强调真实手机夜拍质感）；细节锚点逐一校对（老李车内照左舵翻转、`wang_overtime` 挂钟指向 01:30、`zhou_calligraphy`「远」字、棋摊中国象棋盘）。
- **照片变体**：25 张照片各 5 个同主题随机变体（提示词逐字复用，差异只来自独立种子段），共 125 张；渲染三阶段回退：变体 URL → 基准图 → SVG 场景兜底。
- **私发照片钩子**：王总 `wang_overtime`（"刚加完班"深夜办公室摆拍：表格荧光 + 01:30 挂钟时间证据）与 `milktea_gift`（"给你也点了"：全糖奶茶 + ¥38 小票入镜）——深夜床照式的不适感与糖衣是视觉层的剧情武器。
- **人脸真实感**（SVG 兜底层保留）：确定性眼位不对称（±0.32px）+ 标志性小痣、白平衡偏移与偶发闪光热斑；女主保持"普通里的好看"与 NPC 的"不讲究"形成对照。脸型五档（国字方脸/富态圆脸/清瘦尖脸/瘦长脸/年轻短圆脸）× 发型八档（蓬乱密发→花白背头）——发型也是身份。
- **生成管线**（`pytools/`）：`generate_avatars.py`（女主头像，`--persona <id>` / `--only N` / `--force` / `--dry-run`）、`generate_oldmen.py`（老头头像）、`generate_scenes.py`（场景照片，`--variants` 批量变体、`--seed-offset` 换种子重跑）、`shrink_scenes.py`（raw→web 一次性转换）。
- **dist 瘦身**：raw 768 原图保留于 `pytools/raw_scenes/`（gitignore），游戏用图为 560×420 JPEG q85（600KB→46KB，13×），dist 95M→13M（-86%）。

## 音频系统

Web Audio 三层架构（`src/utils/sound.ts`），零音频文件，音效与背景音乐**独立静音**（标题屏与游戏内各有一对开关，独立 localStorage 偏好）：

- **UI SFX**：发话、红包金币、开口被拒/被拉黑/新的一天等全接线；打字机轻嗒（只对他非玩家非旁白的气泡、且非句读）。
- **BGM**：按 phase/屏幕切换的独立背景音乐（含结局和弦 + 一声长钟——卷首偈的仪式感）。
- **场景音**：log 驱动——只对"新增"条目响一次（读档/重渲染不重放）。

## 安全门（测试强制）

- 全部 50 个老头目标 35 岁以上；女主自称年龄档位 20/24/28/32 全部成年
- 文案不含未成年人相关内容、不含可实操的诈骗细节（无卡号/验证码/收款渠道话术；CI 红线测试覆盖）
- 每个要钱选项必带信任/警惕代价——游戏内没有"免费的钱"
- 红包话术与实际行为一致性验收（autoPacket 同步落账、同一精度记账）

## 架构（复用《华丽人生2》模式）

```
src/
├─ types/        全部类型 + scripts-registry(按老头的脚本注册表)
├─ data/         纯数据：constants(带注释的平衡数值) / targets(主五人) / target-library(库45人)
│                plans(8计划) archetype-packs(4原型话术组) main-packs(主五人各10套话术+incoming台词)
│                script-registry(内容注册表——加老头只加数据不碰引擎)
│                scripts(李) zhou-script(周) wang-script(王) hao-script(豪) chen-script(陈)
│                events(2d6 事件表) / endings(10 结局) / personas(4人设) / voice-cards(话风卡)
│                life-events(老头人生线) / cost-narratives(代价呈现) / library-openers(库个人进场白)
├─ engine/       纯函数 dispatch 状态机(时段/计划偶遇/他来找你/亲和矩阵/麻木日额度/归档/流水/穿帮/产业化
│                /老头人生线/叙事层/红包一致性)
│                + 聊天引擎(要红包判定/人设匹配/红包分层/话术组去重/占位符替换/照片变体哈希)
│  └─ __tests__/ 20 个测试文件 253 条：balance / simulation(5目标自动跑局+产业化线) / dialogue-audit(常驻审计)
│                / v2-systems / v3-persona-context / v4-content / life-events / moments-shop / epilogues
│                / gathas / variants / freshness / packet-consistency / persona-avatars / safeguards
│                / comfort(舒适圈机制+话术红线+对比叙事)
├─ store/        Zustand 薄封装 + localStorage 存档（migrate 补全字段、avatarId 红线测试）
├─ components/   程序化 SVG 头像(兜底链) / 文生图 PNG 渲染器 / 五模块导航 / 计划面板 / 人设浮层
└─ utils/        seed RNG / formatMoney / Web Audio 三层音频(零音频文件)
```

- `dispatch(state, action)` 纯函数引擎，状态全 JSON 可序列化（存档=序列化 state）
- 数值全部集中在 `data/constants.ts`，每项带设计意图注释
- `scripts/ending-distribution.ts`：多策略 × 60 种子的结局分布校准脚本
