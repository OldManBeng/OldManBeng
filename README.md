# 凌晨三点，哥哥

一个以**女性视角**体验「崩老头」现象的严肃现实向聊天经营游戏（v1.0：全内容 + 校准 + 发布打磨）。

> 「崩」在北方方言里意为哄骗、套取。「老头」不是真正的老人，而是对中年男性的戏称——
> 指年轻女性以情感陪伴、暧昧互动为手段，向情感空虚的中年男性小额高频索取钱财的灰色行为。
> 本游戏是这个现象的批判性演绎：你亲自动手，游戏替你记账——钱，和代价。

## 怎么玩

## 游戏循环（30 个游戏日 ≈ 1 小时）

1. **白天（上午）**：账单自动扣（每天 53 元）、2d6 掷随机事件；**上午在线的老头可以白天就聊**（周老师 09:00）。
2. **入夜**：每晚精力 10 点，一场聊天 4 点，最多聊两场半。深夜在线四个老头随你挑——精力就是排程。
3. **聊天**：每人独立四阶段剧情链（试探→熟络→收割→危机，各 8 个故事节点），**一晚只推进一个故事节点**；
   **同一人一天只聊一场**——多线经营是这门生意的本质，也是风险的来源。对话逐字打字机节奏，可点「不等了」直接看完。
4. **开口要红包**：warming 前开口=当冒犯；钱包冷却 3 天（**开局第一天谁的钱包都没解锁**——先认识人）；
   概率 `0.25 + 信任×0.5 − 警惕×0.5 (+孤独加成)`；
   红包分层：奶茶钱 10-50 → 零花钱 50-88 → 心意 88-520（慷慨型 ×1.4）。
   开口失败警惕 +16、成功 +18；警惕每天自然回落 6——「歇几天再开口」是真实战术。
5. **朋友圈穿帮风险**：活跃关系 ≥2 条，风险每天 +7%/条；风险 ≥40% 后每天 25% 概率穿帮
   （被看见的警惕 +30、全员 +6，警惕 85 直接被删；全军覆没触发「评论区」结局）。单线风险每天 −10%。
6. **他也会主动转钱**：信任 ≥60 时每天 8%（附言「天冷了，买件厚点的」）。
7. **产业化分支（M3）**：掷出「姐妹的私信」后，白天面板出现课程卡片——
   **转 300 进群**：代聊群每天替你维护所有关系（信任+5），但话术全网共用（风险 +3/天、麻木 +2/天）；
   开口累计 ≥8 次且买了课 → **判决书结局**（你的号只是七千分之一）。
   **删掉私信**：良心 +5，这条路就此关闭。

## 结局 ×10

还完 / 差一点 / 对不起（坦白）/ 都是真的（撒谎）/ 凌晨三点哥哥（麻木）/ 红色的感叹号 /

**判决书（产业化结局：进了产业链，结局就不由你的良心决定了）**。

结局判定优先级（M4 校准后）：**判决书 > 全员穿帮 / 存折 / 车库（改变一切的大事件）>
账本（达标=还完 / 麻木≥70 / 全被删）> 某晚的一次回答（坦白/嘴硬）> 差一点**。
急功近利会走进麻木结局，克制经营可以走到「还完」，两种玩家都会看到账本后头的人。

另有**崩阿姨镜像彩蛋**：随机事件「评论区的那位阿姨」——被"小帅哥"崩走三万八的老伴的故事，
触发后结局画廊追加她的一段后记。结局画廊的「他们后来」五段后记按老头各自的声口分化——
司机不再说话、老师批改作业从不迟到、生意人止损、90后下线快、工程师删除一项不响。

## 安全门（safeguards 测试强制）

- 所有目标角色 35 岁以上，情感缺口分类仅限成人关系概念
- 文案不含未成年人相关内容、不含可实操的诈骗细节（无卡号/验证码/收款渠道话术）
- 每个要钱选项必带信任/警惕代价——游戏内没有"免费的钱"

## 架构（复用《华丽人生2》模式）

```
src/
├─ types/        全部类型 + scripts-registry(按老头的脚本注册表)
├─ data/         纯数据：constants(带注释的平衡数值) / targets(5老头卡) / personas(4人设)
│                script-registry(内容注册表——加老头只加数据不碰引擎)
│                scripts(李) zhou-script(周) wang-script(王) hao-script(豪) chen-script(陈)
│                events(2d6 事件表) / endings(10 结局)
├─ engine/       纯函数 dispatch 状态机(时段系统/穿帮风险/产业化代聊结算)
│                + 聊天引擎(要红包判定/人设匹配/红包分层)
│  └─ __tests__/ balance / simulation(5目标自动跑局+产业化线) / safeguards
├─ store/        Zustand 薄封装 + localStorage 存档
├─ components/   程序化 SVG 头像(表情随警惕值变化)/各屏幕/风险条/产业化卡片
└─ utils/        seed RNG / formatMoney / Web Audio 合成音效(零音频文件)
```

- `dispatch(state, action)` 纯函数引擎，状态全 JSON 可序列化（存档=序列化 state）
- 零美术/音频资产：SVG 程序化头像 + Web Audio 合成音效
- 数值全部集中在 `data/constants.ts`，每项带设计意图注释
- `scripts/ending-distribution.ts`：多策略 × 60 种子的结局分布校准脚本
  （`npx tsx scripts/ending-distribution.ts`，v1.0 基准：急功近利 12% 达标且 85% 走进麻木；
  克制经营 25% 达标；麻木最小化路线全程仅 12 点麻木）
